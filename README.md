# SonoriX / FFrameWork

Unity 音乐游戏作品，结合固定按键、可移动与改变宽度的判定框、FMOD 音响效果和 Shader 演出。

## 下载运行

在 [Releases](https://github.com/NeroSaika1fe33/FFrameWork/releases) 下载 GitRelease.zip，完整解压后进入 GitRelease 文件夹，运行 My project (1).exe。请保留整个目录中的 Data 文件夹、UnityPlayer.dll 和其他随附文件。

本次提供预编译 Windows 演示包，源码正在整理，尚未上传。

## 基本操作

- A / S / K / L：固定轨道按键。
- Space 或鼠标按下：自由轨道输入。
- 鼠标横向移动：判定框位置。
- 鼠标纵向移动：宽度相关操作。
- 完整规则参见游戏内操作说明。

## 代码来源

本作品使用并改修 [OpenSekai](https://github.com/cubeww/OpenSekai) 的谱面解析、基础音符与判定、对象池及部分演出和工具代码。开发过程中使用了 AI 辅助，当前框架不是从零独立实现。原版权与 MIT 条款见 THIRD_PARTY_NOTICES.md，并随 Release 提供。
