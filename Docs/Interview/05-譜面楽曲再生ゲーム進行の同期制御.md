# 譜面・楽曲再生・ゲーム進行の同期制御

楽曲の再生位置を基準に、ノーツの進行と入力判定を対応させています。OpenSekai の LiveLogic と Converter を主な基盤として利用・改修し、FMOD の時刻を現在のゲーム進行へ接続しています。

## 主なクラスとメソッド

| クラスとファイル | メソッド | 役割 |
| --- | --- | --- |
| FmodSyncedUnityTimer：[ファイル](../../Assets/Scripts/FFrameWork/MusicPlayer/FmodSyncedUnityTimer.cs) | `GetAudioTimeMs()` | FMOD の再生位置をミリ秒で取得 |
| LiveSceneController：[ファイル](../../Assets/Scripts/FFrameWork/Live/Core/LiveSceneController.cs) | `GetCurrentMusicTime()`、`Update()` | 時刻の取得と補正を行い、ゲームを更新 |
| LiveLogic：[ファイル](../../Assets/Scripts/FFrameWork/Live/Core/LiveLogic/LiveLogic.cs) | `OnUpdate()`、`OnInput()` | ノーツを進め、現在の譜面時刻で入力を判定 |
| ChartPlaybackSystem：[ファイル](../../Assets/Scripts/FFrameWork/Live/Core/LiveLogic/ChartPlaybackSystem.cs) | `UpdateTime()`、`UpdateNotes()` | 譜面時刻とノーツ状態を更新 |

流れは、**楽曲の再生時刻 → 譜面の時刻 → ノーツ状態と入力判定 → 表示更新**です。
