# シェーダーを活用したビジュアル演出

[五つの工夫の総覧へ](06-作品の工夫した点.md)

## 概要

楽曲に反応するスペクトラム表示と、時間に応じて動く背景を組み合わせ、電子音楽に合う画面を作っています。

スペクトラムは実際の音声データから変化させ、背景の動きはシェーダーの時間や描画パラメーターから生成しています。

## 音声を画面へ反映する流れ

1. **周波数ごとの強さを取得する。** AudioSpectrum が FMOD の FFT からスペクトラムを読み取ります。低音や高音など、それぞれの成分がどの程度強いかを数値として扱います。
2. **値を滑らかにする。** 小さなノイズを除き、上昇・下降の追従速度を調整して細かい揺れを抑えます。
3. **シェーダーへ渡す。** 処理した配列を _AudioSpectrumData に設定します。
4. **バーと発光を描画する。** 周波数帯の強さに応じて、バーの高さや色、発光を計算します。

音が強くなると対応するバーが高くなり、弱くなると設定した速度で下がります。

## 主なクラスと関数

| ファイルとクラスまたはシェーダー | メソッド・関数 | 役割 |
| --- | --- | --- |
| [AudioSpectrum.cs](../../Assets/Scripts/FFrameWork/MusicPlayer/AudioSpectrum.cs) — AudioSpectrum | `ReadFmodSpectrumData()` | FMOD からスペクトラムを取得 |
| 同上 — AudioSpectrum | `SmoothSpectrumData()`、`Update()` | 値を平滑化し、Renderer のプロパティへ設定 |
| [Audio_Visualizer.shader](../../Assets/Shader/Audio_Visualizer.shader) — VerticalSlice/Live/AudioVisualizer | `SampleSpectrum()`、`frag()` | 配列から値を読み、バーと発光を描画 |
| [Back_Shader.shader](../../Assets/Shader/Back_Shader.shader) — Custom/CyberGlitchBackground | `getVoronoiRandomPos()`、`frag()` | デジタル風の動的背景を描画 |

シェーダーには C# のクラスはありません。表の frag() は、画面の各ピクセルの色を計算する関数です。

## 工夫した点

音声データをそのまま描くだけでなく、平滑化を挟むことで、音への反応と見やすさを調整しています。スペクトラムは主に画面の左右へ配置し、中央のプレイ領域を確保しています。

[MusicVisualizer.prefab](../../Assets/Resources/Prefab/FFrameWork/UI/MusicVisualizer.prefab) では、取得元として FMOD の bus:/Music を設定しています。既存の表示・描画処理を参考にした部分と、本作品向けの調整を区別して説明します。

## 紹介文の例

> 音声スペクトラムをシェーダーに渡し、音楽に反応するビジュアルを作っています。平滑化による動きの調整と動的な背景表現を組み合わせ、電子音楽に合う雰囲気を目指しました。
