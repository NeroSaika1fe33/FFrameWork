# 3. 専用コントローラーの制作

[一覧に戻る](../06-作品の工夫した点.md)

ボタン、つまみ、フェーダーを備えた専用コントローラーを制作しました。リズムに合わせてボタンを叩きながら、つまみやフェーダーを操作することで、楽器や DJ 機材に触れているような手応えを目指しています。

## 実装のポイント

ゲーム側では、固定レーンのボタン入力に加え、フリーレーンの入力、判定枠の位置と幅に関する入力を扱っています。ボタンは押した瞬間、押し続けている状態、離した瞬間を区別し、単発ノーツとロングノーツの両方に対応しています。

Unity の Input System で入力を受け取り、ゲーム内の操作として整理してから判定処理へ渡します。キーボードとマウスでも動作を確認できる構成にしており、固定レーンには A・S・K・L、判定枠の操作にはマウスの移動を割り当てています。

[操作ガイドの画像](../../../Assets/Features/Sprite/Panel/OperationGuide/OperationGuide2.png)に実機の構成を掲載しています。このリポジトリには Unity 側の入力処理を収録しており、配線図やファームウェアは含めていません。
