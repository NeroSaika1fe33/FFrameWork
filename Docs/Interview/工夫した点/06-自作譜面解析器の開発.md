# 6. 制作の背景と、自作譜面解析器への取り組み

[一覧に戻る](../06-作品の工夫した点.md)

## 展示に向けた開発

本作品は、TGS などに学校から出展するための作品として制作しました。出展までの限られた期間で来場者が実際に遊べる状態に仕上げる必要があったため、OpenSekai の既存コードを活用して、譜面解析と演奏処理の基盤を整えました。

主に利用・改修したのは、SUS 譜面を読み込む `Converter` と、演奏進行や入力判定を扱う `LiveLogic` です。その上に判定枠の操作、音響効果、専用コントローラーとの連携などを加え、展示できるゲームとして組み上げました。現在の FFrameWork の譜面解析は、この既存実装をもとにしています。

## SonoriX_Rebuild で進めていること

制作当初から、自分で譜面解析器を設計することにも取り組みたいと考えていました。現在は別プロジェクトの **SonoriX_Rebuild** で、OpenSekai の解析処理から学んだ考え方を参考にしながら、自分のゲームに合わせた譜面解析機能を設計・実装しています。

譜面の記述を読み取る処理、小節・BPM・拍子から時刻を求める処理、ノーツ情報をゲーム側へ渡す処理について、それぞれの役割とデータの流れを自分で説明できる構成を目指しています。既存コードの理解を、仕様の検討や実装の判断につなげることが、この開発の目的です。

SonoriX_Rebuild の解析機能は現在開発中で、公開中の FFrameWork に組み込んだものではありません。
