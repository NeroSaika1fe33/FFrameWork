# 5. 判定枠による独自のゲーム性

[一覧に戻る](../06-作品の工夫した点.md)

固定キーを叩く操作に、判定枠の位置と幅を変える操作を組み合わせました。ノーツのタイミングだけでなく、判定枠をどこに動かし、どの幅にするかも考えながら遊ぶリズムゲームです。

## 実装のポイント

左右に移動するロングノーツでは、判定枠を動かしてノーツの軌跡を追います。押し始めの判定に加え、演奏中もノーツと判定枠が重なっているかを確認しています。

幅を変えるノーツでは、指定された方向へタイミングよく操作します。単発ノーツは成功時に目標の幅へ切り替わり、ロングノーツは操作の進行に合わせて徐々に幅が変わります。幅の変化を譜面の指示と結び付けることで、曲に合わせて操作が展開するようにしています。

幅を変える操作が途中で途切れた場合には、その時点の幅に近い段階へ落ち着くようにしています。成功時だけでなく、中断後も次のノーツへつながる状態を用意しました。
