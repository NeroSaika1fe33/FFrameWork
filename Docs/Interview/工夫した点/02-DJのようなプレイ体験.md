# 2. 音を操る、DJ のようなプレイ体験

[一覧に戻る](../06-作品の工夫した点.md)

音楽に合わせてボタンを押すだけでなく、自分の操作で音の響きが変わる楽しさを取り入れました。Unity から FMOD の音響パラメーターを制御し、ロングノーツの操作とエフェクトを連動させています。

## 実装のポイント

フリーレーンのロングノーツにはフランジャー、判定枠を動かして追いかけるロングノーツにはワブルを割り当てています。幅を変えるロングノーツでは、入力方向に応じてローパスとハイパスを切り替え、操作量に合わせてカットオフを変化させます。

エフェクトは、ノーツの操作が成立している間に適用します。操作が途切れたときやノーツが終わったときには通常の値に戻し、次のフレーズへ効果が残らないようにしています。

操作、画面の動き、音の変化を結び付けることで、DJ のように楽曲へ手を加えながら演奏する感覚を目指しました。
