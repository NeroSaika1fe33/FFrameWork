# 4. シェーダーを活用したビジュアル演出

[一覧に戻る](../06-作品の工夫した点.md)

電子音楽の雰囲気に合う画面を目指し、音楽に反応するスペクトラム表示と、動きのある背景を組み合わせました。スペクトラムは音声データに合わせて変化し、背景はシェーダーで時間に応じた模様を描画しています。

## 実装のポイント

FMOD の FFT から周波数ごとの音の強さを取得し、シェーダーへ渡しています。シェーダーでは、その値をもとにバーの高さや色、発光を変化させています。

取得した値をそのまま表示すると細かく揺れやすいため、小さなノイズを抑え、値が上がるときと下がるときの追従速度を調整しています。音への反応を保ちながら、見やすい動きになるようにしました。

スペクトラムは主に画面の左右へ配置し、中央にはノーツを読むための領域を確保しています。背景の演出と合わせて、プレイ中も音楽の勢いが伝わる画面を目指しています。
