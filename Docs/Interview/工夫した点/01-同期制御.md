# 1. 譜面・楽曲再生・ゲーム進行の同期制御

[一覧に戻る](../06-作品の工夫した点.md)

リズムゲームでは、音楽とノーツの動き、入力判定のタイミングがそろっていることが大切です。本作品では、FMOD から取得した楽曲の再生位置を基準に、譜面の進行と入力判定を更新しています。

## 実装のポイント

楽曲の再生位置を読み取り、開始前の待機時間やタイミング調整を反映したうえで、演奏処理に渡しています。ノーツの表示にも同じ時間軸を使い、画面と判定のずれを抑えています。

譜面に記録された小節位置は、BPM や拍子をもとに秒数へ変換します。また、一時停止から再開する際には、音楽の再生位置とノーツの状態を合わせ直しています。

OpenSekai の `LiveLogic` と `Converter` を基盤として利用し、本作品の FMOD 再生や入力処理に合わせて改修しています。
