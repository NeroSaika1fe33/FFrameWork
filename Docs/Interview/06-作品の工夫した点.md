# 作品の工夫した点

音楽に合わせてボタンを叩く操作に、判定枠の位置や幅の操作、音響効果を組み合わせたリズムゲームです。専用コントローラーと映像演出を通じて、音楽を自分の手で操るような体験を目指しました。

## 五つの工夫

| 項目 | 内容 | 詳細 |
| --- | --- | --- |
| 1. 譜面・楽曲再生・ゲーム進行の同期制御 | 楽曲の再生位置を基準に、ノーツの進行と入力判定をそろえる | [同期制御](工夫した点/01-同期制御.md) |
| 2. 音を操る、DJ のようなプレイ体験 | ロングノーツの操作に合わせて、FMOD の音響効果を変化させる | [DJ のようなプレイ体験](工夫した点/02-DJのようなプレイ体験.md) |
| 3. 専用コントローラーの制作 | ボタン・つまみ・フェーダーで操作する楽しさを作る | [専用コントローラー](工夫した点/03-専用コントローラー.md) |
| 4. シェーダーを活用したビジュアル演出 | 音楽に反応するスペクトラムと動的な背景を描画する | [シェーダー演出](工夫した点/04-シェーダー演出.md) |
| 5. 判定枠による独自のゲーム性 | リズム入力に、判定枠の位置と幅を変える操作を組み合わせる | [判定枠のゲーム性](工夫した点/05-判定枠のゲーム性.md) |

## 制作の背景と今後の開発

学校の TGS などへの出展に向け、OpenSekai の既存コードを活用して演奏処理の基盤を整えました。現在は SonoriX_Rebuild で、その譜面解析の考え方を参考にしながら、自作の解析機能を設計・実装しています。

[6. 制作の背景と、自作譜面解析器への取り組み](工夫した点/06-自作譜面解析器の開発.md)

## 既存コードの利用と改修

主な基盤として、OpenSekai の [LiveLogic](https://github.com/cubeww/OpenSekai/blob/32c91d90c7e18135fef1a214144cce3fb756b3e5/Assets/Scripts/Assembly-CSharp/Sekai/Core/Live/LiveLogic.cs) と [Converter](https://github.com/cubeww/OpenSekai/blob/32c91d90c7e18135fef1a214144cce3fb756b3e5/Assets/Scripts/Assembly-CSharp/Sekai/SUS/Converter.cs) を利用・改修しています。前者は演奏進行と入力・判定処理、後者は SUS 譜面解析の基盤です。

表示・入力などの周辺実装も参考にしており、一部の表示、ノーツ、オブジェクトプール、補助処理には上流コードを改修した部分が含まれます。

開発には AI 支援を利用しています。UI 実装や不具合の調査・修正にも活用しています。著作権表示とライセンス全文は [第三者コードとライセンス](../../THIRD_PARTY_NOTICES.md) に記載しています。
